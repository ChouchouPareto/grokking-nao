# 商业透视思维空间｜开发记录 v0.2.0

> 开发日期：2026-08-30  
> 开发分支：`feature/商业透视思维空间`  
> 技术方案基线：`commercial-space-tech-v1.0.0`

## 本版本完成

- 首页升级为主题搜索入口，支持“商业深思 / 日常发散”双模式。
- 发散前支持用户填写探索方向，或请求 2–3 个 AI 候选后选择。
- 位置权限只在用户主动点击后请求；项目保存约 100 米级坐标和授权状态。
- Idea 数据升级至 schema v4，旧项目打开时补齐模式、方向、位置、分支、节点记录、商业洞察和环境建议。
- 商业深思项目自动请求结构化商业透视：5 个横向方向、5–10 个纵向链路和 1–2 条洞察。
- 商业透视节点先以虚化候选进入画布，用户接受后才成为正式节点和连接。
- 新增节点思考分支与追加式思考记录，刷新后仍通过 IndexedDB 恢复。
- 语义角色加入画布整理逻辑：根节点、横向业态、纵向链路和自由节点使用不同的初始空间约束。
- 新增环境启发：有高德 Web 服务 Key 时可使用真实附近公园；无 Key 时明确返回通用步行/声音建议，不伪造地点。
- 新接口继续复用服务端敏感内容和提示词注入拦截。

## 接口版本

- `POST /api/v1/ai/directions`
- `POST /api/v1/ai/business-lens`
- `POST /api/v1/ai/environment`
- 原 `/suggestions` 与 `/summary` 保持兼容。

## 验证结果

- 后端：31 项 pytest 通过。
- 前端：ESLint、TypeScript、Next.js production build 通过。
- 接口冒烟：方向、商业透视和无地图 Key 环境降级均返回符合契约的 JSON。
- 高德接口参数已按官方地点搜索 2.0 文档核对；真实 POI 尚未配置 Key，因此不标记为已验收。
- 浏览器视觉验收：当前自动化环境没有可用浏览器实例，桌面与 375px WAP 视觉走查待人工完成。

## 已知边界

- 数据仍保存在单浏览器 IndexedDB；正式账号、多端同步和付费权益启动前需迁移服务端数据库。
- 真实附近推荐只查询公园类 POI；后续应结合内测反馈扩展安静空间、书店、街区和展览，并控制地图配额。
- AI 商业透视当前一次展示较多候选，WAP 端需要重点验证侧栏高度、候选浏览与接受操作。
