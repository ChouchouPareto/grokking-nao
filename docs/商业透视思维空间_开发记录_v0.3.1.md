# 商业透视思维空间｜开发记录 v0.3.1

> 开发日期：2026-08-31  
> 开发分支：`feature/商业透视思维空间`  
> 上一基线：`commercial-space-dev-v0.3.0`

## 完成内容

- 删除移动端“向上箭头 + 工具 / 何·论”两个分散胶囊入口。
- 新增统一“面板”悬浮模块：鼠标悬停或触屏点击后展开“工具 / 何 / 论”三个入口。
- 三个入口采用统一 SVG 线性图标、尺寸、间距、选中态和焦点态。
- 移动端选项触控高度约 50px，不依赖 Hover；桌面端保留悬停渐进展开。
- 鼠标悬停关键词时，自动显示两类就地连接引导：
  - 青色实线指向最近且未连接的已有节点，点击线或末端即连接。
  - 紫色虚线指向空白方向，点击后输入新关键词，创建节点并自动连回起点。
- 节点选中后也会保留就地连接入口，供无 Hover 的 WAP 端使用。
- 原“连接”工具保留，继续支持任意远距离节点的明确起点/终点选择。
