# 商业透视思维空间｜开发记录 v0.3.1

> 开发日期：2026-08-31  
> 开发分支：`feature/商业透视思维空间`  
> 上一基线：`commercial-space-dev-v0.3.0`

## 完成内容

- 删除移动端“向上箭头 + 工具 / 何·论”两个分散胶囊入口。
- 新增统一“面板”悬浮模块：鼠标悬停或触屏点击后展开“工具 / 何 / 论”三个入口。
- 三个入口采用统一 SVG 线性图标、尺寸、间距、选中态和焦点态。
- 移动端选项触控高度约 50px，不依赖 Hover；桌面端保留悬停渐进展开。
- 鼠标悬停关键词时，自动显示两类就地连接引导：
  - 青色实线指向最近且未连接的已有节点，点击线或末端即连接。
  - 紫色虚线指向空白方向，点击后输入新关键词，创建节点并自动连回起点。
- 节点选中后也会保留就地连接入口，供无 Hover 的 WAP 端使用。
- 原“连接”工具保留，继续支持任意远距离节点的明确起点/终点选择。
- 扩大预览线的隐形点击命中区，指针进入线身时同步加亮线条与终点，无需精准点击末端标签。

## 验证结果

- TypeScript：通过。
- ESLint：通过。
- Next.js production build：通过。
- `e2e:view-modes`：14/14 通过。
- 回归包含：面板展开、悬停连线、直接连接、新节点并自动连接、2D/3D 切换、LOD、WAP 触控尺寸与运行时错误监测。
- 预览线回归改为点击线段中部的画布坐标，确认线身本身可点，不以末端按钮代替验证。
- 新增“浅色空间舱”立体方案：3D 模式加入景深雾、远近粒子、节点发光核心/外壳/环带、实体化连线与方向流光；2D 模式保持原有清晰平面表达。
- 聚焦交互升级为推进式镜头：焦点节点向前浮起，无关节点沿视线后退；正式关系改为可点击弧线，并仅在聚焦/选中关系上显示方向流光。“全局视图”与 Esc 会同时退出聚焦。
- 将原本独立悬浮在画布右侧的“面板”胶囊收纳到顶部视图控制区，紧邻 3D / 2D 切换；“工具 / 何 / 论”改为向下横向展开，并统一高度、圆角、材质与焦点态。
