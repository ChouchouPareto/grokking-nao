# 商业透视思维空间｜开发记录 v0.3.0

> 开发日期：2026-08-31  
> 开发分支：`feature/商业透视思维空间`  
> 上一基线：`commercial-space-dev-v0.2.1`

## 本版本定位

完成方案 A：在同一个 Three.js 画布中提供 3D 空间与 2D 平面两种观察模式，并解决缩远后文字胶囊大量遮挡的问题。

## 完成内容

- 新增顶部“3D 空间 / 2D 平面”切换器，桌面端和 WAP 端均可用。
- 3D 使用透视相机与旋转游走；2D 使用正交相机、拖动平移和滚轮缩放。
- 两种模式共用业务数据、节点组件、连线与 AI 候选状态，不存在两套画布数据同步问题。
- 建立独立 2D 布局缓存，切换时平滑压平/恢复 Z 深度，不覆盖原始 3D 位置。
- 节点标签新增近/中/远三级 LOD：完整文字、紧凑文字、仅空间点。
- 新增屏幕空间碰撞让位，选中节点、聚焦节点、根节点与分支主干优先显示。
- 全局取景同时适配透视/正交相机，预留标签安全边界，避免节点贴边。
- 2D 模式下 WASD/方向键改为平移；3D 保留 WASD 游走与 Q/E 转向。
- 2D 拖动节点时更新 X/Y，但保留节点原有 Z 深度，返回 3D 后仍保留空间层次。

## 验证结果

- TypeScript：通过。
- ESLint：通过。
- Next.js production build：通过。
- 新增 `pnpm e2e:view-modes` 视图回归：9/9 通过。
- 回归覆盖：多关键词拆分、3D 默认视图、2D 切换、数据不丢失、远景 LOD、WAP 切换与运行时错误监测。

## 技术边界

- 2D 是同场景的正交观察模式，不是独立流程图编辑器。
- LOD 阈值目前基于相机距离/正交缩放比，后续可根据真实内测项目的节点数量调参。
- 旧的 `e2e-full.cjs` 仍使用改版前首页选择器，已不适用于新首页；本版以新的视图专项回归为验收依据。
