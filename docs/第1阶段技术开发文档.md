> 配套文档：`Grokking恼_PRD_v1.0_第一版.md`、`AI产品Vibe Coding通用技术栈手册.md`、`技术适配声明.md`
> 本文档只覆盖第 1 阶段（切片 1）。AI 开发时不得提前实现 AI 建议、语义场景、首页管理等后续能力。

## 一、阶段目标

- **用户任务（一句话）**：用户从一个"念头"开始，把关键词放入 3D 空间、手动连接它们，并标记出至少一条"这是新发现"，关闭再打开后一切仍在。
- **交付范围（对齐 PRD 8.1 P0 的子集）**：
  1. 首页"我有一个念头"输入 → 创建 Idea（自由文本 + 系统生成标题）；
  2. 3D 思考空间：逐个新增关键词 + 批量粘贴拆分；
  3. 3D 自动布局 + 受控镜头（旋转/缩放/平移）；
  4. 手动连接两个节点（可选一句说明，无强制关系类型）；
  5. 将连接标记为"这是新发现"（可选填原因，计入数量）；
  6. 节点聚焦（一层相邻关系高亮，其余弱化）+ 一键返回全局；
  7. 编辑 / 删除节点（删除有关联节点时提示连接数）；
  8. 本地自动保存（IndexedDB）+ 保存状态反馈 + 重新打开恢复。
- **阶段产物**：可运行的 Web 前端（正式产品切片，非一次性调试页）。
- **验收标准**：见第十一节。
- **明确不做**：AI 建议引擎、语义场景氛围、首页重命名/复制/删除/JSON 导入导出、撤销重做、导出图片、移动端复杂编辑。这些分别属于切片 2/3/4 与 P1。
- **本阶段打通的主链路片段**：`输入念头 → 创建 Idea → 添加关键词 → 3D 布局浏览 → 手动连接 → 标记新发现 → 本地保存 → 重新打开恢复`。

## 二、技术适配摘要

- 引用《技术适配声明》结论：开发路径 = **纵向切片**；数据**本地优先**；本阶段无 AI、无后端。
- 本阶段采用：Next.js（App Router）+ TypeScript strict + Tailwind CSS；Git 版本管理。
- 本阶段启用按需模块：Three.js + R3F（3D 画布）、d3-force（布局）、idb（IndexedDB）、zustand（全局客户端状态）。
- 本阶段偏离/暂缓：无后端服务（切片 2 才引入 FastAPI）；无服务端数据库；暂缓关系型数据库/SSE/向量库。
- 开发路径：纵向切片（交互本身是产品能力）。

## 三、技术栈与模型

- 框架：Next.js 16.3.2（App Router）、React 19、TypeScript strict、Tailwind CSS 4。
- 3D：three 0.185.x、@react-three/fiber 9.7.x、@react-three/drei（OrbitControls、Html 标签）。
- 布局：d3-force 3.0（forceX/Y/Z 三维力导向）。
- 状态：zustand 5（节点/连接/选择/聚焦/模式/保存状态跨画布与面板共享）。
- 本地存储：idb 8（IndexedDB 封装，数据库 `grokking`，对象仓库 `ideas`）。
- 模型：**本阶段无模型调用**，不做真实冒烟（切片 2 开始）。
- ID 生成：`crypto.randomUUID()`（内置，无需依赖）。

## 四、环境与配置

- 无需 `.env`、无 API Key（本阶段纯本地）。
- 启动端口：前端开发服务使用 **3010**（3000 已被占用），命令 `npm run dev -- -p 3010`。
- 外部依赖：无；所有依赖走 npm。

## 六、数据、资产与状态

### 持久化方式
IndexedDB（idb 封装），数据库 `grokking`，仓库 `ideas`（key = Idea id）。**本地优先**，无服务端数据库。

### 数据结构（schemaVersion = 1）

```ts
type Vec3 = { x: number; y: number; z: number };

interface ThoughtNode {
  id: string; text: string;
  source: "user" | "ai";        // 本阶段均为 "user"
  status: "formal" | "candidate"; // 本阶段均为 "formal"
  position: Vec3;
  isPositionPinned: boolean;    // 用户拖动后为 true
  createdAt: number; updatedAt: number;
}

interface ThoughtEdge {
  id: string;
  sourceNodeId: string; targetNodeId: string;
  source: "user" | "ai";        // 本阶段均为 "user"
  status: "formal" | "candidate";
  note?: string;                // 可选连接说明
  isDiscovery: boolean;         // "这是新发现"
  discoveryNote?: string;       // "为什么这是新发现"
  createdAt: number; updatedAt: number;
}

interface Idea {
  id: string; schemaVersion: number;
  title: string; seedText: string;
  createdAt: number; updatedAt: number; lastOpenedAt: number;
  nodes: ThoughtNode[]; edges: ThoughtEdge[];
  discoveryCount: number;       // 由 isDiscovery 边数推导，冗余存储便于首页展示
}
```

### 状态机（本阶段子集）
- 节点：`formal`（用户创建即 formal；candidate/rejected 属切片 2）。
- 连接：`formal`；`discovery` 是 formal 连接上的 `isDiscovery` 布尔属性（对齐 PRD 18.2）。
- 保存状态：`saving → saved | failed`（PRD 18.4）。
- UI 模式：`browse | connect`；聚焦：`focusedNodeId | null`。

### 数据校验与迁移
- 打开 Idea 时按 `schemaVersion` 判断；未知版本不覆盖数据、给出提示（对齐 PRD 23 的迁移边界，本阶段仅 v1）。
- 所有写入走统一 `saveIdea()`，写前把 `updatedAt` 更新。

## 七、API / 工具设计

本阶段**无后端 HTTP API**。对外边界是本地数据层（`lib/db.ts`）与状态层（`lib/store.ts`）的接口：

| 层 | 接口 | 说明 |
| --- | --- | --- |
| db | `getIdea(id)` / `listIdeas()` / `putIdea(idea)` / `deleteIdea(id)` | IndexedDB 原子读写 |
| store | `createIdea(seed)` / `loadIdea(id)` / `addNodes(texts[])` / `removeNode(id)` / `addEdge(a,b)` / `toggleDiscovery(edgeId)` / `setFocused(id)` / `setMode(m)` 等 | 业务动作，内部触发自动保存 |
| graph | `positionsRef` + `startLayout()` / `relayout()` | 非响应式逐帧位置，供 3D 组件读取 |

## 十一、验收清单（产品经理照做）

1. 打开首页，看到主输入框"我有一个念头"和空状态引导。
2. 输入一段念头 → 进入 3D 空间，看到系统生成的标题（可修改）。
3. 逐个添加 ≥5 个关键词，节点出现在空间中并自动布局。
4. 一次粘贴多行/多词，能拆分为多个独立节点。
5. 用鼠标旋转、缩放、平移画布，无需方向键。
6. 连接两个节点（不填说明也能完成）；尝试连接自己、重复连接会被拦截。
7. 选中一条连接，标记"这是新发现"，可选填原因；顶栏新发现数 +1。
8. 点击一个节点 → 该节点及相邻节点高亮、其余弱化；一键返回全局。
9. 拖动一个节点；刷新/关闭重开后位置保持（pin）。
10. 编辑、删除一个节点；删除有关联连接的节点时看到连接数提示。
11. 观察保存状态出现"已保存"；关闭浏览器重开，Idea 内容和位置恢复。

## 十二、风险与待确认项

- 3D 标签可读性与 60 节点基线性能：MVP 用 HTML 标签（中文安全、可点击）；若帧率跌破 30 FPS，按 PRD 14.1 降级（弱化非聚焦标签/粒子）或迁移 troika 文本。属技术方案，AI 自主处理。
- 批量粘贴分隔规则：PRD 15.1.1 说"具体分隔规则待交互设计确认"。本阶段采用**换行/逗号/顿号/分号 均按分隔符拆分**，空行忽略，作为临时方案并在界面可预览拆分结果。
- 系统自动生成标题：本阶段无 AI，采用**取念头前 N 字 + 截断**的规则化临时方案（显式标注，切片 2 替换为 LLM 生成）。
- 需要产品经理决定的问题：**无**（以上均为可逆临时方案，不改变产品目标/成本/范围）。
