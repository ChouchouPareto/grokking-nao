# Grokking恼｜v0.5.0 认知宇宙

一个由 AI 陪伴的 3D 空间思考工具，把零散念头组织成可探索的关键词网络，并帮助你发现此前没有想到的新连接。

## 使用场景与产品目的

Grokking恼面向需要梳理复杂问题、探索商业机会或进行创意发散的人。它把传统线性笔记改造成可交互的 2D/3D 思维空间，让用户从一个想法出发，逐步发现关键词之间的关系、分支和可行动方向。

产品当前的核心目的，是验证“空间化思考 + AI 陪伴”能否帮助用户降低整理复杂想法的门槛，并形成可回看、可继续推进的思考过程。

## 核心体验

- 在空间画布中添加、连接和探索关键词
- AI 围绕节点提供联想、潜在关系和启发式追问
- 通过“何 · Context”理解当前思考上下文
- 通过“论 · Synthesis”形成阶段性总结
- 支持桌面端与移动端访问
