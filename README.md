# Grokking恼

一个由 AI 陪伴的 3D 空间思考工具，把零散念头组织成可探索的关键词网络，并帮助你发现此前没有想到的新连接。

## 在线体验

[打开 Grokking恼](https://sq5hv7u6n0fli8hftgkg9.apigateway-cn-beijing.volceapi.com/)

当前处于邀请体验阶段，需要使用有效邀请码进入。

## 核心体验

- 在空间画布中添加、连接和探索关键词
- AI 围绕节点提供联想、潜在关系和启发式追问
- 通过“何 · Context”理解当前思考上下文
- 通过“论 · Synthesis”形成阶段性总结
- 支持桌面端与移动端访问
